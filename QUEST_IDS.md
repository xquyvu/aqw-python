# AQW Quest IDs

Local reference for quests used by `bot\sandsea_camels.py`.

| Quest ID | Quest name | Map | Monster |
| --- | --- | --- | --- |
| 916 | Dissertations Bupers Camel | sandsea | Bupers Camel |
| 917 | Crafty Creepers: A Favorite of Mine | sandsea | Cactus Creeper |

## Sources and lookup

- [AQW World quest ID list](https://www.aqwworld.com/2017/01/quest-id-aqw-latest-and-updated.html):
  use the browser's Find command to search for a quest name. The numeric ID
  precedes the name. Both entries above appear in the 901-1000 section.
  The list uses "Crafty Creepers - A Favorite of Mine" for quest 917.
- [Zhoom's quests](https://aqwwiki.wikidot.com/zhoom-s-quests#2):
  quest names and objectives.
- [Oasis](https://aqwwiki.wikidot.com/oasis):
  confirms the map's internal name is `sandsea` and lists both monsters.

The external ID list labels itself as updated April 10, 2021; it is not an
official game API or a guaranteed current database. These entries were looked
up on November 14, 2026. Quest 916 was also confirmed by successful server
turn-in responses in this session; quest 917 has not yet been confirmed live.

The repository does not currently have a built-in quest-name-to-ID lookup.
For additional quests, look up the name in the linked ID list and verify it
against the game before adding it here.
